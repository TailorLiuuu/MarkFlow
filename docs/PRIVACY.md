# 数据与隐私边界

仓库不保存真实设备 MAC、电脑身份、绑定令牌、生产记录、用户目录、部署配置、管理端代码、服务端数据库或运行截图。示例 MAC 使用本地管理地址 `02:00:00:00:AB:CD`，批次使用 `DEMO`，不对应现场设备。

软件运行时需要读取真实 MAC 并保存打印记录。默认用户数据目录沿用 Qt 的 `InfinLab/LabelDesk`，用于兼容旧版；这些运行时数据不得提交 Git 或加入发布包。Windows 机器令牌通过 DPAPI 保护。

启用云连接后，客户端向配置的管理服务发送电脑标识、主机名、系统版本、打印机及串口清单、模板状态和打印结果。模板与任务只按数据解析，不执行服务端下发的任意脚本。公开服务地址不是凭据；实际凭据由每台电脑运行时生成。

发布包只能从干净源码构建，并由 `scripts/package_release.py` 从 `dist/MarkFlow` 打包。禁止直接压缩正在使用的软件数据目录。不要将现场日志、截图、模板中的真实静态设备号、凭据或客户生产数据放入 GitHub Issue、Release 或附件。

`scripts/privacy_check.py` 检查提交文件边界、常见凭据、绝对用户路径和静态 MAC 示例。它是基础检查，不能保证识别所有秘密；发布前仍需检查完整 diff 与资源内容。

打包时另用 `scripts/audit_package.py` 解开两个 EXE 中的应用字节码，扫描应用常量及编译路径，并核对模板和图标与已审查源码一致。包目录拒绝运行时身份文件、数据库、日志及打印记录；第三方依赖保持干净构建的原始内容。
